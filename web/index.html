Fitur

Fitur lengkap.
Mudah digunakan.

Kernel sing-box

Core performa tinggi dengan gVisor, QUIC, uTLS, Clash API, dan conntrack.

Multi-protokol

VMess, VLESS, Trojan, Shadowsocks, TUIC, Hysteria, WireGuard, SSH — satu client.

Privacy first

Tanpa telemetry, tanpa iklan. Semua koneksi eksplisit dan di bawah kendali Anda.

Material Design

Antarmuka modern dengan tema, config editor, dan manajemen profil.

Multi-ABI

Build optimal untuk arm64-v8a dan armeabi-v7a. Ringan di perangkat lama.

Open source

Lisensi GPLv3. Audit kodenya, bangun sendiri, berkontribusi.

Cara Pakai

Import — Pilih Server & Connect

  1. Import config

    Tempel URL subscription, clipboard, atau file JSON sing-box.

  2. Pilih server

    Cek latency tiap profil, pilih yang tercepat.

  3. Hubungkan

    Satu tap. Mode TUN berjalan tanpa root.

  4. Terhubung

    Pantau throughput dan status koneksi real-time.

FAQ

Pertanyaan umum.

Apakah BITS Box gratis?

Ya. Gratis, open source (GPLv3), tanpa iklan dan tanpa telemetry.

Apakah perlu root?

Tidak. Mode TUN berjalan lewat VpnService Android standar.

Kenapa tidak ada di Play Store?

Distribusi saat ini via GitHub Releases agar update lebih cepat dan transparan. Semua build bisa diverifikasi dari source.

Bagaimana cara import config?

Mendukung import via URL subscription, clipboard, maupun file JSON sing-box.
